# ARTIFACT-UI-PLAN.md — 圣遗物配置与计算界面

> 状态：规划稿。本文为前端实现接口，不改变模拟器规则，也不承诺尚未有数据来源的效果。
> 目标：在现有圣遗物套装选择器、五件装备模型和属性编辑器之上，逐步提供完整、可核对、易操作的圣遗物配置体验。

## 1. 产品目标

圣遗物是角色伤害输入的一部分。用户需要在同一处完成四件事：

1. 找到套装，按上线时间、品质或名称筛选。
2. 选择角色实际穿戴的五个部位，以及每个部位所属套装。
3. 输入或修改主词条、副词条，立即看到面板属性变化。
4. 知道哪些套装层级会参与本次计算，并能回到详情核对原文。

界面优先服务“配置一套可复现的构筑”。它不生成随机圣遗物，不猜测未发布的词条数值，不把空白占位件当成有属性的装备。

## 2. 现有基础与缺口

当前代码已经提供：

- `ArtifactSetDefinition`：套装名称、品质、图标、套装效果和目录排序字段。
- `ArtifactLoadout`：`flower`、`plume`、`sands`、`goblet`、`circlet` 五个部位。
- `ArtifactPiece`：部位、套装 id、主词条、副词条。
- `ArtifactPicker`：套装搜索、品质筛选、倒序上线排序、件数选择和词条编辑入口。
- `ArtifactStatsEditor`：五个部位的主词条与副词条输入。
- 设备适配层：空属性占位件只用于激活套装层级，真实输入的属性才进入面板和伤害计算。

需要补齐的体验：

- 当前选择器把“套装快捷选择”和“五件实际装备”混在一个窗口，用户不容易发现混搭套装的表达能力。
- 套装卡片是 `article`，只有底部文字按钮可装配；整张卡不可用键盘选择，操作层级不统一。
- 件数控件是全局单值。它适合快速预览 2 件或 4 件套，却不能表达 2+2、1+1+1+1+1 或每个部位不同套装。
- 词条编辑区域在选择器内展开，五件装备一起出现时纵向过长，移动端难以定位部位。
- 当前角色卡只显示套装摘要。完整主词条、副词条和每件装备需要进入独立详情界面。
- 空白属性、已录入属性、套装层级和计算结果需要用不同文案表达，不能继续使用“词条 N/5”这种容易被理解为副词条条数的说法。

## 3. 信息架构

### 3.1 入口一：角色构筑卡

角色卡继续保持紧凑，只展示可快速比较的信息：

```text
圣遗物  绝缘之旗印                         4件
         2件套 · 元素充能效率 +20%          编辑 ›
         已录入 3/5 件属性
```

整行打开“圣遗物配置”页面或面板。角色卡不展开五件属性，不展示大段套装原文，不出现内部支持状态标签。

### 3.2 入口二：圣遗物配置面板

建议使用独立的 `ArtifactLoadoutPanel`，桌面端为宽面板，移动端为全屏页面。布局：

```text
┌ 圣遗物配置 · 雷电将军                         [关闭] ┐
│ 套装快捷选择  [搜索] [品质] [按上线时间倒序]          │
│ 当前层级      [2件套] [4件套]  已录入 3/5 件属性       │
├───────────────────────────────────────────────────────┤
│ 生之花  [套装] [主词条] [副词条摘要]       编辑 ›       │
│ 死之羽  [套装] [主词条] [副词条摘要]       编辑 ›       │
│ 时之沙  [套装] [主词条] [副词条摘要]       编辑 ›       │
│ 空之杯  [套装] [主词条] [副词条摘要]       编辑 ›       │
│ 理之冠  [套装] [主词条] [副词条摘要]       编辑 ›       │
├───────────────────────────────────────────────────────┤
│ 套装效果与计算说明                         [展开详情]  │
│ 面板变化：攻击 +… · 充能 +… · 双暴 +…                  │
│ [取消]                                   [保存配置]    │
└───────────────────────────────────────────────────────┘
```

套装快捷选择仍保留现有倒序目录。选择快捷套装时只填充尚未明确指定的部位，并把每个部位的套装 id 写入 `artifactLoadout`；用户随后可以替换任意一件。快捷件数只表达默认填充建议，不能覆盖用户已经编辑的部位。

### 3.3 入口三：单件编辑面板

点击某个部位进入 `ArtifactPieceEditor`：

- 部位标题和图标，例如“空之杯”。
- 套装选择器，支持当前套装、搜索、最近使用和清空。
- 主词条选择器与数值输入。
- 四行副词条编辑；每行包含类型和数值，允许删除空行。
- 当前件属性摘要和对总面板的增量预览。
- 保存、取消、清除此件。

单件编辑不自动随机强化，不根据品质推断数值。没有已核验数据时，输入框保持空白，面板增量为零。

### 3.4 入口四：套装详情抽屉

套装名称、图标、品质和完整中文效果放在详情抽屉。抽屉显示：

- 1、2、4 件效果的原文，按件数升序排列。
- 当前穿戴数量与已激活层级。
- 仅对当前构筑生效的层级高亮。
- “计算说明”折叠区，说明空白属性不会增加面板，条件效果按战斗时间轴触发。
- 不在主卡片显示内部枚举名或英文来源文本。

## 4. 数据与兼容边界

### 4.1 规范模型

`ArtifactLoadout` 是长期规范模型。每个部位独立记录：

```ts
interface ArtifactPiece {
  slot: ArtifactSlot;
  setId: string;
  mainStat: EquipmentStat;
  substats: readonly EquipmentStat[];
}
```

`artifactSetId`、`artifactPieces` 保留为旧版快捷选择和旧存档兼容字段。新 UI 保存时优先写完整 `artifactLoadout`，同时写入可推导的旧字段，直到持久化版本完成迁移。

### 4.2 属性输入规则

- 所有百分比在界面按百分数输入，例如 `46.6`，存储为 `0.466`。
- 固定值直接按面板数值输入。
- 元素伤害必须同时选择元素；缺少元素时不写入计算。
- 空值显示为空，不显示虚假的 `0` 词条；保存时由规范化函数写成零值占位件。
- 花和羽的固定主词条约束，只有在数据源发布并通过校验后才启用。没有来源时保留通用选择器，不能凭经验硬编码。
- 副词条顺序不影响计算；UI 顺序只服务阅读和编辑。
- 输入超出有限数值范围时显示字段错误，阻止保存该件，不改变其他四件。

### 4.3 套装计数

套装层级由五件实际 `setId` 计数得出。快捷件数不直接作为引擎输入：

- 2 件同套装：激活 2 件层级。
- 4 件同套装：同时激活 2 件和 4 件层级。
- 2+2：两个套装各激活 2 件层级。
- 1 件或混搭不足 2 件：不激活普通 2/4 件层级；未来单件套按数据定义处理。
- 部位缺失时显示“未装备”，不补造属性。

## 5. 交互状态

| 状态 | 卡片显示 | 可执行操作 |
|---|---|---|
| 未装备 | `+ 添加圣遗物` | 打开套装浏览或单件配置 |
| 快捷套装已选 | 套装名、件数、`已录入 0/5 件属性` | 修改任意部位、编辑词条 |
| 部分部位已录入 | 套装摘要、`已录入 N/5 件属性` | 继续编辑，保存 |
| 混搭套装 | `2+2` 或部位套装摘要 | 打开五件列表，逐件替换 |
| 有未保存修改 | 面板显示“有未保存修改” | 保存、取消、关闭拦截 |
| 保存后结果过期 | 既有结果保留，显示配置已变更 | 重新执行模拟 |
| 套装效果依赖时间轴 | 主卡只显示摘要 | 详情中说明触发条件；结果时间轴负责证明触发 |
| 缺少来源数值 | 字段为空或 `暂无已核验数值` | 不猜值；允许用户手动输入已知构筑值 |

关闭、返回和 Escape 的规则：有未保存修改时先显示确认；点击保存后返回角色构筑卡，并将焦点还给触发该面板的按钮。

## 6. 响应式与可访问性

- 桌面端：左侧五件列表，右侧单件编辑和套装效果；宽度不足时自然堆叠。
- 平板端：五件列表保持单列，编辑区放到列表下方。
- 移动端：全屏面板；部位使用可折叠原生按钮，一次只展开一个部位；底部固定保存栏并预留安全区。
- 所有编辑、保存、删除、展开、切换套装控件最小触控高度 44px。
- 套装卡使用原生 `<button>`，不可使用只有 `role="button"` 的 `div`。
- 卡片可访问名称包含套装名、品质、当前部位数和是否已装备；图标使用空 `alt`，不重复朗读名称。
- 套装效果详情使用 `aria-expanded` 和 `aria-controls`；筛选结果计数使用 `aria-live="polite"`。
- Tab 顺序：搜索与筛选 → 五件部位 → 当前部位编辑 → 套装详情 → 保存栏。弹层关闭后恢复触发按钮焦点。
- 文案保持中文；英文套装名只作为搜索别名，不进入主显示和屏幕阅读器名称。
- 长中文套装名、长效果和 200% 缩放必须换行，不依赖 hover tooltip 才能读到完整内容。

## 7. 组件拆分建议

| 组件 | 责任 |
|---|---|
| `ArtifactLoadoutPanel` | 面板状态、保存/取消、焦点恢复、五件部位编排 |
| `ArtifactSetBrowser` | 搜索、品质、上线顺序、套装详情入口 |
| `ArtifactSetCard` | 原生选择按钮、图标、名称、件数和效果摘要 |
| `ArtifactPieceList` | 五件部位顺序、缺失状态、已录入状态 |
| `ArtifactPieceEditor` | 单件套装、主词条、副词条编辑和校验 |
| `ArtifactStatRow` | 统计类型、数值、元素选择和错误状态 |
| `ArtifactBonusSummary` | 2/4 件激活层级和条件说明 |
| `ArtifactDeltaPreview` | 由公共适配器计算的面板增量，不在组件内复制伤害公式 |

现有 `ArtifactPicker` 可以先作为 `ArtifactSetBrowser` 的实现基础。现有 `ArtifactStatsEditor` 的规范化和计数函数继续复用；不要在新组件复制 `normalizeArtifactLoadout` 或属性求和逻辑。

## 8. 实施顺序

1. **ART-UI-001：移除旧件数歧义** — 角色卡统一使用“已录入 N/5 件属性”，保留现有套装层级行为。
2. **ART-UI-002：套装卡语义化** — 将套装卡改为原生按钮，统一焦点、选中、详情和装配操作。
3. **ART-UI-003：五件部位面板** — 在不改变模拟器 API 的前提下，将快捷套装映射到完整 `artifactLoadout`。
4. **ART-UI-004：单件编辑面板** — 把 `ArtifactStatsEditor` 拆成可折叠的单件编辑，加入错误、取消和保存状态。
5. **ART-UI-005：套装详情与条件说明** — 复用现有中文套装数据和效果展示，主界面隐藏内部支持枚举。
6. **ART-UI-006：持久化迁移** — 为完整五件模型增加版本字段，旧版 `artifactSetId/artifactPieces` 可恢复为快捷套装，再由用户确认具体部位。
7. **ART-UI-007：面板增量与结果链路** — 面板属性预览、运行指纹、结果过期提示全部读取同一适配器输出。
8. **ART-UI-008：移动端和无障碍验收** — 360×800、768×1024、桌面、200% 缩放及键盘流程。

## 9. 验收标准

- 用户能为五个部位分别选择套装，正确表达 4 件、2+2、混搭和空部位。
- 用户编辑任一主词条或副词条后，角色卡摘要和面板预览同步更新。
- 保存后模拟器读取的 `artifactLoadout` 与界面展示完全一致；空白件不会增加伤害。
- 套装 2/4 件效果按实际 `setId` 计数激活，不能由显示层单独决定。
- 选择器顺序仍为最新套装到最旧套装，搜索中文名、英文别名和中文效果有效。
- 所有主要动作可用键盘完成；关闭后焦点恢复；没有不可聚焦的伪按钮。
- 结果过期、未保存修改、缺少数值和条件效果均有中文且可理解的状态说明。
- 不出现 `+3命`、`当前登场`、英文套装主文案或内部“已接入模拟”枚举标签。

## 10. 测试计划

### 组件测试

- 套装卡原生按钮可用 Enter/Space 选择，当前装备有 `aria-pressed` 或等价语义。
- 五件部位顺序固定为花、羽、沙、杯、冠；空部位显示空状态。
- 2+2、4 件和单件套计数与 `activeSetBonusKeys()` 一致。
- 主词条、副词条百分数输入转换正确；非法、无穷和缺少元素的输入不能保存。
- `已录入 0/5 件属性` 到 `已录入 5/5 件属性` 文案准确，不再使用“词条 N/5”。
- 保存、取消、Escape 的未保存拦截和触发按钮焦点恢复。

### 集成测试

- 改变任一圣遗物属性会改变初始面板预览和运行指纹。
- 套装更换、部位混搭和删除不会残留旧部位属性。
- 旧版只含 `artifactSetId/artifactPieces` 的存档可读，不能凭空生成非零词条。
- 页面模拟使用的 `ArtifactLoadout` 与角色卡展示完全相同。

### 浏览器验收

- 360×800：面板无横向溢出，保存栏不遮挡最后一行。
- 768×1024：部位列表和编辑区可定位，长中文效果自然换行。
- 桌面四列角色卡保持可比较，不因展开详情改变其他卡片高度。
- 键盘 Tab、Enter、Space、Escape 完成完整选择、编辑、保存流程。
